## Источники и уровни данных

Анализ использует опубликованный [набор Университета Рединга](https://doi.org/10.17864/1947.000384) и [статью Rodriguez-Garcia et al., 2022](https://doi.org/10.1016/j.lwt.2022.113837). Автор портфолио не проводил лабораторный эксперимент. Оригинальные документы в `source/` не изменены. URL, размеры и SHA-256 шести документов записаны в [манифесте](../source/download_manifest.json); авторство и CC BY 4.0 указаны в [DATA_LICENSE.md](../DATA_LICENSE.md).

## Методология и исторические материалы

Единица физического анализа — производственная партия. Среднее рецептуры рассчитано с равным весом трёх партийных средних. Основная метрика — сила разрушения в Н. Сопротивление проникновению имеет другую единицу, Н·с; его нельзя подменять силой разрушения. Составы и дозировки различаются одновременно, поэтому сравниваются целые рецептуры.

Раздел 7 notebook содержит четыре Welch-сравнения с поправкой Holm и анализ чувствительности ANOVA/Dunnett. При n=3 оценки неопределённости и тесты зависят от непроверенных допущений. Отсутствие значимости не доказывает одинаковое качество. Новых тестов по опубликованным сенсорным средним нет. Подробные допущения и типы интервалов сохранены в notebook и `statistical_results.csv`.

Notebook сохранён без изменения, включая исторический раздел 13 подготовки для Yandex DataLens. Его таблицы и словарь полей пригодны для проверки структуры данных; описание будущего дашборда относится к прежнему этапу. Действующее представление — две страницы Streamlit. Старые API-скрипты не нужны для выполнения notebook.

Отчёт аудита датирован 11 октября 2026 года. Предложения о будущих тестах и BI в нём описывают состояние на тот момент. `audit_report.md` остаётся в корне, поскольку notebook использует его наличие при определении корня проекта. `analysis_overview.png` также сохраняется: notebook создаёт этот график с партийными значениями и неопределённостью, которых нет в упрощённом приложении.

## Воспроизведение и проверки

Приложение: Python 3.12, `pip install -r requirements.txt`, затем `python -m streamlit run app.py`. Пути к данным и assets определяются относительно app.py; активация окружения не обязательна.

Для полного исследования в том же окружении установите библиотеки notebook:

```bash
python -m pip install numpy==2.3.5 openpyxl==3.1.5 pdfplumber==0.11.9 python-docx==1.2.0 scipy==1.17.0 matplotlib==3.10.8 nbconvert==7.17.1 ipykernel==7.2.0
python -m ipykernel install --sys-prefix --name cookies --display-name "Cookies (Python 3.12)"
python -m nbconvert --to notebook --execute biscuit_recipe_analysis.ipynb --ExecutePreprocessor.kernel_name=cookies --ExecutePreprocessor.timeout=180 --output executed_notebook.ipynb --output-dir /tmp
```

На Windows замените `/tmp` на существующую локальную папку, например `$env:TEMP`. Запускайте команду из корня проекта; используйте `python.exe` своего окружения. Notebook пересоздаёт десять CSV и `analysis_overview.png`. Для проверки без изменения рабочего репозитория сначала скопируйте проект в отдельную временную папку. Выполнение не требует сети или ключей. Выходной notebook не нужно коммитить.

```bash
python -m unittest discover -s tests -v
python -m pip check
```

Для браузерной проверки отдельно установите Playwright и Chromium:

```bash
python -m pip install playwright==1.63.0
python -m playwright install chromium
```

Запустите Streamlit на localhost:8501, затем в другом терминале:

```bash
python tests/browser_smoke.py --screenshots /tmp/cookies-screenshots
```

На Windows для `--screenshots` используйте локальную папку. Проверяются обе страницы на ширине 1440, 1024 и 390 px, реальные расстояния между подписями и столбцами, изображения, шрифты, источники, таблица и загрузка CSV. Установка Playwright нужна только для проверки, не для приложения.
