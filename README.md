# Снижение сахара в песочном печенье: выбор рецептуры на основе данных

Проект № 3 аналитического портфолио. Цель — сравнить стандартную рецептуру печенья с четырьмя вариантами частичной замены сахарозы растворимыми пищевыми волокнами и обосновать кандидатов для дальнейших производственных испытаний.

**Текущий этап: аудит опубликованных экспериментальных данных.** Отчёт подготовлен 11 октября 2026 года. Материалы для размещения на GitHub подготовлены 12 октября 2026 года для просмотра и скачивания. Статистический анализ следующего этапа, Jupyter Notebook и дашборд ещё не выполнялись.

## Сравниваемые рецептуры

| Название в проекте | Оригинальное обозначение ингредиента |
|---|---|
| Стандартная рецептура | Control |
| Кукурузный декстрин № 1 | Nutriose® FM06 |
| Кукурузный декстрин № 2 | Promitor® SGF 70R |
| Более растворимый инулин | Orafti® HSI |
| Длинноцепочечный инулин | Fibruline™ Instant |

Каждый заменитель рассматривается отдельной экспериментальной группой.

## Ключевые ограничения данных

- Производственных повторов — три партии на рецептуру. Отдельные печенья и технические повторы вложены в партии.
- Доли удаления добавленной сахарозы по рецептурной таблице различаются: 31,48%, 35,11%, 22,11% и 34,84%. Заявленные 30% нельзя автоматически присваивать всем вариантам.
- Индивидуальные сенсорные оценки не опубликованы; доступны средние и результаты статистического анализа авторов.
- Обнаружены пропуски измерений, конфликты единиц и проблемы отдельных формул/сводок. Подробности приведены в отчёте.

Исходные файлы сохранены без изменения. Искусственные экспериментальные данные не создавались. Отчёт фиксирует состояние на дату аудита; содержащаяся в нём фраза об отсутствии GitHub-репозитория относится к 11 октября 2026 года.
