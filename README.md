# Снижение добавленной сахарозы в песочном печенье

Проект № 3 аналитического портфолио. **Бизнес-вопрос: насколько можно сократить количество добавленной сахарозы в рецептуре песочного печенья с помощью пищевых волокон и какие изменения качества при этом возникают?**

Компания хочет уменьшить добавление сахарозы и сохранить физические и сенсорные характеристики максимально близкими к стандарту. Сравниваем четыре исследованные рецептуры со стандартной; универсальный предел снижения сахара по этому эксперименту не устанавливаем. Снижение добавленной сахарозы не означает измеренное снижение всех сахаров готового изделия.

**Текущий этап: подготовка данных и логики исследования.** В notebook выполнены воспроизводимая загрузка, проверки и описательные расчёты. Финальные статистические тесты, доверительные интервалы, выбор рецептуры и дашборд ещё не выполнены. Отчёт первого этапа от 11 октября 2026 года сохранён.

## Сравниваемые рецептуры

| Название в проекте | Оригинальное обозначение ингредиента |
|---|---|
| Стандартная | Control |
| Кукурузный декстрин № 1 | Nutriose® FM06 |
| Кукурузный декстрин № 2 | Promitor® SGF 70R |
| Более растворимый инулин | Orafti® HSI |
| Длинноцепочечный инулин | Fibruline™ Instant |

Каждый заменитель рассматривается отдельной экспериментальной группой. Состав загружается непосредственно из таблицы 2 статьи. «Г на 100 г муки» — рецептурное соотношение, а не процент ингредиента в готовом печенье. Масса ингредиента с волокнами не равна измеренной массе чистых волокон.

## Подготовленные данные

| Файл | Строк | Уровень данных |
|---|---:|---|
| [recipes.csv](data/recipes.csv) | 5 | Полный состав рецептуры, фактическое снижение сахарозы, соответствие оригинальному ингредиенту и флаг Orafti |
| [physical_measurements.csv](data/physical_measurements.csv) | 905 | Одно существующее значение с рецептурой, условной партией, показателем, единицей, ячейкой и флагами |
| [physical_batch_means.csv](data/physical_batch_means.csv) | 225 | Рецептура × партия × показатель; основной вход будущих статистических сравнений |
| [sensory_means.csv](data/sensory_means.csv) | 200 | Опубликованное среднее по рецептуре и сенсорному признаку; новые тесты недоступны |
| [metric_dictionary.csv](data/metric_dictionary.csv) | 55 | 15 физических и 40 сенсорных показателей с русскими названиями, объяснениями и источниками |
| [physical_recipe_summary.csv](data/physical_recipe_summary.csv) | 75 | Рецептура × физический показатель: среднее трёх партий, описательный SD, контроль, разности и число партий |

Из 15 физических показателей два — массы группы до и после выпечки, служащие контекстом расчёта потерь. Предварительная основная метрика качества — сила разрушения в Н; остальные 12 показателей качества — дополнительные.

Каждая партия имеет равный вес после усреднения вложенных измерений. В тесте на излом доступны 10/10/9 измерений на три партии каждой рецептуры. Адреса десяти отсутствующих ячеек сохранены в партийной таблице; измерения не заполнены нулями. Генерируемый `measurement_id` обозначает запись, а не реальный ID печенья. Даты и лабораторные ID остаются пустыми.

Для DataLens физическая и сенсорная витрины отдельные. Они соединяются с составом и словарём как «многие к одному»; напрямую объединять их наблюдения нельзя. Детальная схема ключей, расчётов, ограничений и пяти будущих графиков находится в разделе 3 notebook. Название будущего дашборда: **«Как снижение сахарозы влияет на качество печенья»**.

Показатели разных единиц не выводятся на общую числовую шкалу. Разность влажности и потерь массы выражена в процентных пунктах. SD между партиями — описание разброса, а не доверительный интервал. Новые p-value и интервалы пока не рассчитываются; сенсорные p-value сохранены исключительно как результаты авторов.

## Как воспроизвести подготовку

Используйте Python 3.12 и запускайте Jupyter из корня репозитория. Версии библиотек, на которых выполнены проверки:

```bash
python -m pip install pandas==2.2.3 numpy==2.3.5 openpyxl==3.1.5 pdfplumber==0.11.9 python-docx==1.2.0 "jupyterlab>=4,<5"
jupyter lab biscuit_recipe_analysis.ipynb
```

Выполните все ячейки сверху вниз. Notebook проверяет SHA-256 исходников, читает все листы через pandas, извлекает состав из PDF, создаёт шесть CSV в `data/` и повторно проверяет неизменность исходников. Все расчёты выполняются локально; повторная загрузка данных из сети не требуется. CSV используют UTF-8 с BOM, запятую как разделитель и точку как десятичный знак. Пропуски остаются пустыми.

Исходники пока остаются в `source/`, а `data/` содержит подготовленные данные. Материалы аудита сохранены для проверки; состав будущей публичной версии согласуем отдельно.

## Ключевые ограничения данных

- Производственных повторов — три партии на рецептуру. Отдельные печенья и технические повторы вложены в партии.
- Доли удаления добавленной сахарозы по рецептурной таблице различаются: 31,48%, 35,11%, 22,11% и 34,84%. Заявленные 30% нельзя автоматически присваивать всем вариантам.
- Индивидуальные сенсорные оценки не опубликованы; доступны средние и результаты статистического анализа авторов.
- Обнаружены пропуски измерений, конфликты единиц и проблемы отдельных формул/сводок. Подробности приведены в отчёте.
- Для физического анализа размеры подтверждены в мм, сила разрушения — в Н; противоречивые подписи исходников сохранены и отмечены. Реология и DP пока не включены в аналитические витрины из-за вопросов качества и независимости.
- Для одного сенсорного признака (`Dry` при четвёртом укусе) в S1 отсутствует определение. Это отмечено в словаре; крайние значения шкалы не восстанавливаются предположением.

Исходные файлы сохранены без изменения. Искусственные экспериментальные данные не создавались. Отчёт фиксирует состояние на дату аудита; содержащаяся в нём фраза об отсутствии GitHub-репозитория относится к 11 октября 2026 года.

## Следующие этапы

После согласования второго этапа: утвердить методы сравнения с контролем с учётом трёх партий и неизвестной парности дней, оценить эффекты и интервалы при обоснованной модели, затем сформировать рекомендации для испытаний и собрать интерактивный дашборд в Yandex DataLens. Его превью и опубликованная ссылка появятся после отдельного этапа.

Потребуются уточнения состава Orafti, экспериментальных дней и причины пропусков теста на излом. Для самостоятельной сенсорной статистики нужна индивидуальная выгрузка оценок. Отсутствие значимого различия не означает эквивалентность; технологические допуски и итоговый балл качества не задаются самостоятельно.
