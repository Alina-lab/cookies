# Снижение добавленной сахарозы в печенье

**[Дашборд](https://cookies-alina-lab.streamlit.app/)** | **[Jupyter Notebook](biscuit_recipe_analysis.ipynb)**

## Цель исследования

Выяснить, насколько можно уменьшить добавленную сахарозу при частичной замене пищевыми волокнами и какие рецептуры стоит испытывать дальше. Производителю важно сохранить привычные вкус и структуру: сахар влияет не только на сладость, но и на цвет и поведение теста при выпечке.

## Данные

[Опубликованный эксперимент Университета Рединга](https://doi.org/10.17864/1947.000384) и [научная статья](https://doi.org/10.1016/j.lwt.2022.113837): стандартное печенье и четыре варианта, по три независимые производственные партии на рецептуру. Для анализа использованы опубликованные экспериментальные данные. Собственные лабораторные измерения не проводились.

Кукурузные декстрины Nutriose и Promitor и инулиновые ингредиенты Orafti и Fibruline сравниваются раздельно. Масса коммерческого ингредиента не равна массе чистого пищевого волокна.

## Основные результаты

- **Максимальное сокращение сахарозы — 35,11% с кукурузным декстрином № 2.** Средняя сила разрушения ниже стандарта на 27,35%, а оценка подгорелого вкуса выше на 27,62 пункта.
- **Длинноцепочечный инулин ближе всего к стандарту по средней силе разрушения:** 56,24 Н против 61,91 Н (−9,15%) при сокращении сахарозы на 34,84%. При этом размеры и сопротивление проникновению тоже изменились.
- **С кукурузным декстрином № 1 изменения горечи и подгорелого вкуса меньше, чем с другими заменителями:** +5,67 и +5,94 пункта. Это интенсивность ощущений по шкале 0–100, а не оценки вкусности.

Все навески указаны на **100 г муки**. Стандартная дозировка сахарозы — **29,45 г**; процент её сокращения относится к рецептуре, а не ко всем сахарам готового печенья.

## Ход работы

1. **Проверка данных.** Изучила эксперимент, листы Excel, единицы и пропуски. Отделила независимые партии от вложенных измерений отдельных изделий.
2. **Подготовка таблиц.** В pandas сохранила происхождение измерений до ячейки, рассчитала партийные средние и фактическое сокращение сахарозы.
3. **Исследовательский анализ.** Сравнила механические свойства, размеры, влажность, цвет и опубликованные сенсорные средние со стандартом.
4. **Статистический анализ.** Выполнила сравнения силы разрушения методом Welch с поправкой Holm; Dunnett использовала для проверки чувствительности к допущениям. По сенсорным средним новых тестов нет.
5. **Визуализация и рекомендации.** Собрала приложение на Streamlit и Plotly и выделила три направления следующих производственных испытаний.

## Рекомендации

Испытывать **декстрин № 2**, если приоритет — сильнее сократить сахарозу; **длинноцепочечный инулин**, если важна близость к стандартной силе разрушения; **декстрин № 1**, если важны меньшие изменения горечи и подгорелого вкуса. При повторных выпечках проверить отмеченные физические и вкусовые изменения по заранее согласованным требованиям.

Ни один вариант пока не доказан как полноценная замена стандарта. Трёх партий мало для уверенного решения о внедрении; допустимые изменения качества не заданы. Нет индивидуальных сенсорных оценок и измерений всех сахаров готового продукта. Тип и дозировка заменителя меняются вместе; у Orafti общая масса рецептуры отличается от остальных. Отсутствие значимых различий не доказывает одинаковое качество.

## Запуск

Python 3.12, Windows PowerShell из корня проекта:

```powershell
py -3.12 -m venv .venv-app
.\.venv-app\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-app\Scripts\python.exe -m streamlit run app.py
```

Откройте `http://localhost:8501`. На Linux/macOS используйте `.venv-app/bin/python`. Приложение читает готовые CSV и не требует исходных документов, ключей или внешней базы данных.
